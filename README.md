# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核会话与冻结版本均保存在浏览器本机，可离线编辑；打开多个浏览器窗口即可模拟多位复核员并发复核。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖（含循环依赖拦截）。
- **带版本号的复核会话**：每个步骤维护 `revision` 与传递依赖指纹；确认时建立编号会话（RS-0001、v1/v2…），确认前同时核对步骤版本、前置依赖指纹与上游确认状态。
- **复核席位与 FIFO 队列**：同一步骤同一时刻只发放一个席位（带 30 秒租约、自动续约）；席位已满时其他复核员排队，席位释放后按顺序到位，到位时再次做版本核对，过期基线不会生效。
- **失效传播**：材料、用量、危险项、控制措施、安全说明或前置依赖改动会抬升步骤版本，使本步骤及全部传递下游的既有确认立即失效，必须重核后才能冻结；非安全字段（目的、设备、时间等）不影响确认。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- 提交复核后，复核人可逐条添加批注（相同评注全局去重，只保留一条）、标记解决、确认或退回。
- **离线暂存与联网合并**：断网期间批注与确认写入会话草稿并暂存；联网后按时间顺序合并，评注重复只留一条，确认会重新核对版本/安全/席位；版本过期或席位被占时保留草稿并给出「定位重试 / 排队等待」入口。
- 所有步骤均为**当前版本的有效确认**且安全信息完整后才能冻结；冻结快照记录每个确认对应的会话号、复核员与步骤版本；冻结后只能从该版本创建修订稿（全部确认作废、步骤升版重核）。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 并发与版本模型

| 概念 | 说明 |
| --- | --- |
| 步骤版本 `rN` | 安全相关字段（材料、用量、危险项、控制措施、安全说明、依赖）每改一次 +1。 |
| 依赖指纹 | 传递依赖链上每个前置的 `id@revision` 串联；任一前置改版，下游指纹即变化。 |
| 复核会话 | 每位复核员对每步一条，带编号 `RS-xxxx` 与会话版本 `vN`；打开时捕获基线，基线失效后需「改基重核」。 |
| 确认引用 | 确认记录会话号、复核员、`stepRevision`、依赖指纹、安全内容哈希；任一不符即判为「待重核」，且不能进入冻结。 |
| 席位/队列 | 单席位 + FIFO 排队，跨窗口通过 `localStorage` storage 事件与租约协调。 |
| 离线暂存 | 断网操作绑定暂存当下的步骤版本；联网合并时重新核对，失败保留草稿。 |

跨窗口协调数据独立存储在 `sologsb-1027-coord-v2`，席位、队列与暂存区会在多个标签页之间合并。

## 双窗口演示

1. `npm run dev` 后打开两个浏览器窗口，右上角分别选择不同复核员（周宁 / 王颖 / 赵岚）。
2. 两人在「安全复核」对同一步骤点确认：第一人领取席位（约 1.3 秒后核对通过、确认生效），第二人自动排队并在席位释放后接续处理。
3. 第一人持席期间，在另一窗口的「流程编写」修改该步骤材料或其前置：确认被阻止，相关步骤与下游全部变为「待重核」，冻结门控同步更新。
4. 点「模拟断网」添加批注/确认，再「模拟联网」：观察暂存区合并、评注去重与过期确认的重试定位。

## 模型逻辑测试

```bash
npm run test:model
```

覆盖席位并发、FIFO 晋升、持席期间改版拦截、失效传播、前置门控、离线去重/过期保留、冻结与修订等 12 个场景（纯函数逻辑，不启动浏览器）。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
